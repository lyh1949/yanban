怎么用

两步准备，然后开口就行

第一次使用按提示完成设置，之后就能直接对话办事。

1装好之后要做的准备

  • 1
    开权限 —— 点右上角「设置 → 权限设置」，开启「无障碍」和「悬浮窗」两项开关。
  • 2
    填钥匙 —— 点「设置 → Agent 设置」，粘贴 DeepSeek 官网申请的 API Key。

密钥相当于一把「钥匙」，没有它助手就无法联网思考。前往申请 →

2开始使用

  • 1
    打开 App，进入「言办 Agent」聊天页。
  • 2
    在底部输入框用大白话写下要办的事。
  • 3
    点「发送」，然后看它自己操作就行。
“帮我在美团定一杯咖啡” “打开微信，给张三发一句‘在吗’”

过程中它会一条条汇报进度；拿不准时会停下来问你；想停就点右下角红色「停止」按钮。

常见问题

你可能想问的

去「设置 → 权限设置」确认两个开关都开了。部分手机还要在系统设置里允许它后台运行、别把它杀掉。

到「设置 → Agent 设置」里把 API Key 粘贴进去即可。

微信这类 App 会「藏」起来不让助手看，助手会自动改用截图来认字找位置，一般能自己处理好。

失败时会自动存一份日志，位置在手机目录 Android/data/com.rushi.agent/files/logs/ 下。
